# ft_linear_regression

Predict the price of a car from its mileage with a linear function trained
by gradient descent. No library does the math: everything is written by hand.

## Install

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

matplotlib is only needed for `plot.py`.

## Usage

```bash
python3 predict.py    # before training: always 0 (theta0 = theta1 = 0)
python3 train.py      # train on data.csv, save thetas to thetas.json
python3 predict.py    # estimate the price for a given mileage
python3 plot.py       # bonus: data + regression line
python3 precision.py  # bonus: MAE, MSE, RMSE, R²
```

## Files

| File | Role |
|---|---|
| `data.csv` | Dataset: `km,price` for 24 cars |
| `train.py` | Gradient descent, writes `thetas.json` |
| `predict.py` | Asks for a mileage and prints the estimated price |
| `plot.py` | Bonus: scatter plot of the data and the trained line |
| `precision.py` | Bonus: measures how well the model fits the data |
| `thetas.json` | Generated by `train.py` (git-ignored) |

## How it works

**Hypothesis**

```
estimatePrice(mileage) = theta0 + (theta1 * mileage)
```

**Training** (batch gradient descent, `m` = number of cars):

```
tmpTheta0 = learningRate * 1/m * Σ (estimatePrice(mileage[i]) - price[i])
tmpTheta1 = learningRate * 1/m * Σ (estimatePrice(mileage[i]) - price[i]) * mileage[i]
theta0 -= tmpTheta0
theta1 -= tmpTheta1     # both updated simultaneously
```

These are the derivatives of the cost `J = 1/(2m) * Σ (estimatePrice(mileage[i]) - price[i])²`,
so each step moves the line in the direction that reduces the error.

**Scaling**: mileages go up to 240000, which makes the theta1 step explode
(divergence). Training uses `x = km / km_max` (values in [0, 1]), then converts
back to raw km: `theta0 = a`, `theta1 = b / km_max`.

**Stopping**: the loop runs until the cost improves by less than
`EPSILON = 1e-12` (converged), or exits with an error if it diverges.
Learning rate: `0.001`.

## Results

| | Value |
|---|---|
| theta0 | ≈ 8499.59 |
| theta1 | ≈ -0.0214489 |
| MAE | 557.84 (≈ 9% of the average price) |
| RMSE | 667.57 |
| R² | 0.733 (mileage explains 73% of the price variation) |

The thetas match the exact least-squares solution, so this is the best
possible line for this data.
